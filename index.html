Sensor Configuration

Use the below command set to enable sensors as per requirement:

Sensor Settings Command
All sensors off AT+SENSORMASK=0
On Ambient only AT+SENSORMASK=217
On Temperature only AT+SENSORMASK=218
On Humidity only AT+SENSORMASK=220
On both Temperature, Ambient AT+SENSORMASK=219
On both Humidity, Ambient AT+SENSORMASK=221
On both Temperature and Humidity AT+SENSORMASK=222
Temperature, Humidity, Ambient, all three on AT+SENSORMASK=223
